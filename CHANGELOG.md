# ConnectX Changelog

## [Admin Dashboard 1.0.0] - 2026-11-25
### Added
- **Multi-Admin RBAC & Database Support (`20261125020000_admin_console_levels`)**: Added all 8 administrator tiers (`SUPER_ADMIN`, `PLATFORM_ADMIN`, `SECURITY_ADMIN`, `BUSINESS_ADMIN`, `FINANCE_ADMIN`, `CONTENT_MODERATOR`, `SUPPORT_ADMIN`, `CUSTOM_ADMIN`), ban/moderation fields, business restrictions, feature versioning/eligibility, staged releases, and SHA-256 tamper-evident audit hash chaining (`previous_hash`, `entry_hash`).
- **NestJS Multi-Admin APIs (`/backend/src/modules/admin`)**: Expanded `AdminController`, `AdminService`, and `AdminOperationsService` across all 13 governance modules (A–M) with strict server-side `@Roles` + `@RequirePermissions` checks, Redis caching on overview telemetry, CSV analytics export, and zero E2EE private message exposure.
- **Next.js Super Admin Web Console (`/admin-web`)**: Built Next.js 15 + React 19 + TypeScript + Tailwind CSS + shadcn/ui + TanStack Query console featuring ConnectX green/white light & dark themes, in-memory JWT + TOTP MFA authentication, and real API-driven workflows across Overview, Users, Admins, Roles & Permissions, Feature Control & Rollback, Business Management, Moderation, Finance, Notifications, Analytics (CSV/PDF export), System Settings, Tamper-Evident Audit Center, and Controlled Developer Release Center.
- **Automated Tests**: Added `backend/test/admin-console.spec.ts` and `admin-web/src/lib/admin-rbac.test.ts`.

## [Database 1.0.0] - 2026-11-25
### Added
- **Enterprise PostgreSQL + Prisma + Redis Schema (`backend/prisma/schema.prisma`)**: Full 11-domain schema (A–K) covering 70+ tables (`users`, `user_profiles`, `user_credentials`, `user_sessions`, `user_devices`, `otp_verifications`, `user_privacy_settings`, `user_contacts`, `user_blocks`, `conversations`, `conversation_members`, `messages`, `message_receipts`, `message_reactions`, `message_attachments`, `message_edits`, `message_deletions`, `pinned_messages`, `starred_messages`, `groups`, `group_members`, `group_roles`, `group_permissions`, `group_invites`, `communities`, `community_members`, `community_groups`, `community_announcements`, `business_accounts`, `business_verifications`, `business_categories`, `business_catalogs`, `products`, `product_images`, `customers`, `customer_labels`, `customer_notes`, `business_orders`, `quick_replies`, `business_automations`, `calls`, `call_participants`, `call_events`, `notifications`, `notification_preferences`, `notification_jobs`, `notification_templates`, `admin_users`, `admin_roles`, `admin_permissions`, `admin_user_roles`, `admin_role_permissions`, `admin_activity_logs`, `admin_approvals`, `feature_modules`, `feature_flags`, `feature_dependencies`, `app_settings`, `app_releases`, `subscription_plans`, `user_subscriptions`, `payment_transactions`, `invoices`, `refunds`, `media_objects`, `upload_sessions`, `support_tickets`, `system_logs`, `backup_records`, plus `user_key_bundles`, `abuse_reports`, `push_subscriptions`, `system_announcements`, `idempotency_records`).
- **Version-Controlled SQL Migrations**: Initial UTC `TIMESTAMPTZ(3)` schema with E2EE & deterministic order check constraints (`20261125000000_init/migration.sql`) and composite cursor/partial/GIN/BRIN indexes, monthly range-partitioned `messages_archive_partitioned` & `system_logs_partitioned`, and `purge_expired_connectx_records()` (`20261125010000_partitioning_indexes_retention/migration.sql`).
- **Database Seeding, Verification & Operations Docs**: Added idempotent `backend/prisma/seed.ts` (`npm run db:seed`), `backend/prisma/scripts/verify-schema.sql`, automated Jest DDL test suite (`backend/test/database-schema.spec.ts`), and `backend/docs/DATABASE.md` (ER diagram, indexing strategy, relationships, backup/restore PITR runbook).

## [Backend 1.0.0] - 2026-11-25
### Added
- **Node.js / NestJS Enterprise Backend (`/backend`)**: Complete modular backend with `/api/v1` versioning, OpenAPI/Swagger documentation (`/api/v1/docs`), PostgreSQL Prisma ORM schema + initial SQL migration (`prisma/migrations/20261125000000_init/migration.sql`), Redis cache, RabbitMQ dead-letter retry queues, Socket.IO `/realtime` WebSocket + WebRTC signaling gateway, Coturn HMAC TURN integration, and Docker Compose (`postgres`, `redis`, `rabbitmq`, `coturn`, `backend`, `nginx`).
- **11 Backend Modules**: Authentication (Argon2id, OTP, rotating refresh tokens with reuse detection, TOTP MFA, device sessions), Users (profiles, privacy, presence, E2EE public key bundles, contacts, blocks, reports), Messaging (E2EE ciphertext-only private chats, admin read isolation, reactions, receipts, replies, forwarding, edits, deletes, disappearing messages, magic-byte file uploads), Groups, Communities, Calling, Business (catalog, CRM labels/notes, deterministic orders & analytics), Notifications, Payments (Stripe webhook signature verification & idempotency), Administration (Super/Dept/Custom roles, approvals, audit logs), and System Management (health, feature flags, maintenance mode, announcements, backup manifests).
- **Automated Backend Tests**: Jest unit & Supertest integration tests (`backend/test/crypto-and-upload.spec.ts`, `backend/test/connectx-api.integration.spec.ts`).

## [2.0.0] - 2026-11-25
### Added
- **Main Dashboard (`DashboardScreen`)**: Real-time overview metrics, global cross-entity search (chats, directory members, catalog SKUs, support tickets), Notification Center modal, online contacts strip, and recent activity feed.
- **Rich Messaging (`ChatDetailPane` & `ChatsScreen`)**: In-thread search, active/archived & type filters, pinned message banner, emoji quick-picker, reply, forward, edit, soft-delete, pin, star, reactions, read receipts, Photo Picker (`PickVisualMedia`), generic file attachments (`OpenDocument`), catalog quote cards, `RECORD_AUDIO` voice notes, and archive/mute/disappearing-message settings.
- **Hub (`HubScreen`, `ContactsAndCallsComponents`, `StatusTabContent`, `ChannelsScreen`)**: Contacts directory (add, search, block/unblock, profile sheet, Android share invite), Voice/Video/Group calling history & active call overlay with live timer and mic/camera/speaker controls, Text/Image/Video Status feed with privacy & reactions, and Broadcast Channel info/member permissions.
- **Business Desk & Billing (`BusinessScreen`, `BusinessBillingCrmTab`)**: Product Details dialog, Business Registration & Verified badge, deterministic Business Analytics, CRM customer labels/notes, Subscription Plans (`STARTER`, `GROWTH`, `ENTERPRISE`), and Invoice History.
- **Settings, Multilingual i18n & Support (`MoreScreen`, `ProfileScreen`, `SupportScreen`, `ConnectXStrings`)**: Live English (`en`), Hindi (`hi`), and Assamese (`as`) UI switching, `SYSTEM`/`LIGHT`/`DARK` theme switching, 2FA/last-seen/notifications toggles, Connected Devices management, personal account data purge, Help Center FAQ, and Support Ticket tracking + Live Desk escalation.
- **Domain Repositories & Security**: Split data layer (`MessagingRepository`, `CommunityRepository`, `BusinessRepository`, `ConnectXRepository`), expanded `firestore.rules`, and updated `DeterministicRulesEngineTest`.

## [1.0.0] - 2026-11-25
### Added
- **Authentication & Identity**: Google Sign-In via Jetpack Credential Manager (`GetSignInWithGoogleOption` + silent `GetGoogleIdOption`) gated in `MainActivity` with `key(uid)` session isolation.
- **Enterprise Messaging (`ChatsScreen`)**: Real-time Firestore Direct, Group, and Business Support conversations, deterministic SLA priority triage (`URGENT`, `HIGH`, `NORMAL`, `LOW`), thread workflow locking (`OPEN`, `PENDING`, `RESOLVED`), zero-permission Android Photo Picker attachment notes, and `/shortcut` quick-reply expansion.
- **Broadcast Channels (`ChannelsScreen`)**: Arattai-inspired `WORKSPACE` and `PRIVATE` channels, join/leave membership sync, pinned announcements, and post acknowledgements.
- **Business Desk (`BusinessScreen`)**: Product & service catalog, arithmetic-verified order pipeline (`totalCents == quantity * unitPriceCents`, terminal state locking on `FULFILLED`/`CANCELLED`), and deterministic away/greeting rules.
- **RBAC & Governance (`GovernanceScreen`)**: PII-isolated workspace directory (`/directory_profiles`), role-based capability matrix (`ADMIN`, `BUSINESS_MANAGER`, `AGENT`, `MEMBER`), admin role editor, and immutable `/audit_logs`.
- **Security & Testing**: Hardened `firestore.rules` with `firebase-blueprint.json`, `firestore.test.js` emulator verification suite, and JVM unit/Robolectric tests.
- **AI-Free Guarantee**: Strictly deterministic business rules; zero AI/ML dependencies or integrations.
